        但 javadoc 插件 plugin.xml（3.12.0）中不存在 additionalparam 参数（grep 0 命中），
        仓内也无任何 ${additionalparam} 引用 → 该属性为惰性遗留，不构成实际关闭；

【负向探针记录】（探针为任务临时目录构造文件，非仓库文件；已留证并删除，见第六节）
  探针A —— 缺注释（构造无任何 javadoc 的公共类/构造器/方法）:
    命令: javadoc -Xdoclint:all -Xmaxwarns 1000000 --release 17 -quiet -d <out> p/Probe.java
    结果: 4 个警告 ——
      「警告: 没有注释」×4（类 / 构造器 doThing / getNum 等公共成员）; 输出「4 个警告」; EXIT=0
    加 -Werror 复跑: 「错误: 发现警告, 但指定了 -Werror」，1 个错误 + 4 个警告，REAL_EXIT=1
    → 证明: doclint missing 组对缺注释产生告警；maven 侧 failOnWarnings=true 与 -Werror 等价拦截。
  探针B —— 有注释但缺标签（类有注释、方法缺 @param/@return、类缺构造器注释）:
    结果: 4 个警告 ——
      「a没有 @param」「b没有 @param」「没有 @return」「使用不提供注释的默认构造器」; EXIT=0
    → 证明: 缺参说明、缺返回说明、默认构造器缺注释三类 missing 告警全部可被门禁捕获。
  假绿反例（同类探针，记录教训）:
    - 未提供完整 classpath 时，javadoc 输入存在「程序包不存在/找不到符号」错误则 doclint
      告警不再输出（router 模块实测: 40 错误 / 0 警告 → 看似 0 告警实为假绿）。
    - 因此本任务全部自查与基线盘点均构建完整 -classpath（~/.m2 全量 6957 个 jar
      + 19 个模块 target/classes）后执行，杜绝该假绿路径。
